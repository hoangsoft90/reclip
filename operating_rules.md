# operating_rules.md — Operating Rules

> Rules that ALL agents must follow when working on this project.

## 🚫 Never Do
1. **Never build APK locally** — no `flutter build`, no `gradlew` on local machine
2. **Never hardcode UI strings** — always use `AppStrings.xxx`
3. **Never throw exceptions in adapters** — catch all, return `MetadataResult.failed()`
4. **Never commit without running `flutter test`** — 25 tests must pass
5. **Never push without checking build** — verify GitHub Actions passes
6. **Never modify `database.g.dart`** — auto-generated by build_runner
7. **Never use `setState` for business logic** — use Riverpod providers
8. **Never add new packages without checking** — verify not already in pubspec.yaml

## ✅ Always Do
1. **Read `.agents/skills/reclip-project.md`** before coding
2. **Read `openspec/specs/<feature>/spec.md`** before modifying a feature
3. **Run `flutter test`** before committing
4. **Run `flutter analyze`** to check for errors
5. **Use `AppStrings`** for all user-facing text
6. **Use `IdGenerator.generate()`** for new IDs (UUID v4)
7. **Follow feature-first folder structure**
8. **Write commit messages in conventional format** (feat/fix/docs/chore)

## Build Process
```bash
# Code changes
flutter test                    # Verify tests pass
flutter analyze                 # Check for errors
git add -A && git commit -m "..."  # Commit
git push origin main            # Push → GitHub Actions builds APK
```

## Code Review Checklist
- [ ] No hardcoded strings (use AppStrings)
- [ ] No exceptions thrown from adapters
- [ ] DB changes have migration path
- [ ] New features have OpenSpec
- [ ] Tests added for new logic
- [ ] No unused imports
- [ ] No `print()` in production code (use MetricsLogger)

## File Conventions
| Type | Naming | Example |
|------|--------|---------|
| Screen | `*_screen.dart` | `library_screen.dart` |
| Widget | descriptive | `quick_link_card.dart` |
| Service | `*_service.dart` | `quick_save_service.dart` |
| Adapter | `*_adapter.dart` | `reddit_adapter.dart` |
| Controller | `*_controller.dart` | `facet_filter_controller.dart` |
| Spec | `spec.md` | `openspec/specs/library/spec.md` |

## Git Rules
- Branch: `main` (no feature branches for now)
- Commit format: `<type>: <description>` (feat/fix/docs/chore)
- Always add footer: `🤖 Generated with Codebuff\nCo-Authored-By: Codebuff <noreply@codebuff.com>`
- Never force push
- Never rewrite history
