# Kiến trúc Code

## Cấu trúc thư mục — Feature-First

```
lib/
├── main.dart                          # Entry point + Riverpod providers
├── app.dart                           # MaterialApp + NavigationBar + lifecycle hooks
│
├── core/                              # Cross-cutting concerns
│   ├── constants/
│   │   ├── app_strings.dart           # Tất cả UI strings (không hardcode)
│   │   └── platforms.dart             # PlatformInfo + enum re-exports
│   ├── database/
│   │   ├── database.dart              # Drift AppDatabase (6 tables + FTS5 + DAO)
│   │   └── database.g.dart            # Auto-generated by build_runner
│   ├── network/
│   │   ├── http_client.dart           # Shared Dio instance
│   │   └── connectivity_service.dart  # Online/offline detection
│   ├── url/
│   │   ├── url_normalizer.dart        # Clean tracking params → canonical URL
│   │   └── platform_detector.dart     # Detect platform from URL
│   └── utils/
│       └── id_generator.dart          # UUID v4 wrapper
│
└── features/                          # Feature modules
    ├── share_intent/                  # Nhận URL từ Android Share Sheet
    ├── quick_save_toast/              # Toast overlay "Saved ✓"
    ├── library/                       # Grid/List view + filter + thumbnails
    ├── search/                        # FTS5 full-text search
    ├── item_detail/                   # Chi tiết item + Open Original
    ├── smart_save/                    # BottomSheet thêm chi tiết
    └── metadata/                      # Enrichment (adapters + orchestrator)
```

## Data Flow

```
[Android Share Sheet]
        │
        ▼
ShareIntentHandler ──→ QuickSaveService ──→ AppDatabase (SQLite)
        │                     │
        │                     ├──→ UrlNormalizer.canonicalize()
        │                     └──→ PlatformDetector.detect()
        │
        ▼
QuickSaveToast (Overlay)        EnrichmentOrchestrator (background)
                                       │
                                       ├──→ MetadataAdapterFactory.forPlatform()
                                       │         ├── RedditAdapter
                                       │         ├── YouTubeAdapter
                                       │         ├── XAdapter
                                       │         ├── TikTokAdapter
                                       │         ├── InstagramAdapter
                                       │         └── GenericOpenGraphAdapter
                                       │
                                       ├──→ ThumbnailDownloadService
                                       │         └── flutter_cache_manager
                                       │
                                       └──→ MetricsLogger
```

## Database Schema

```
saved_items (16 columns)          thumbnails (7 columns)
    ├── item_collections (3) ──→ collections
    └── item_tags (3) ──→ tags

saved_items_fts (FTS5 virtual table)
    └── Triggers: INSERT, UPDATE, DELETE sync
```

## Layer Separation

| Layer | Location | Responsibility |
|-------|----------|---------------|
| **Presentation** | `features/*/presentation/` | UI widgets, screens |
| **Application** | `features/*/application/` | Business logic, services |
| **Domain** | `features/metadata/domain/` | Interfaces, models |
| **Core** | `core/` | Shared utilities, DB, network |

## Key Files

| File | Role |
|------|------|
| `main.dart` | Provider definitions + app entry |
| `app.dart` | MaterialApp + lifecycle + share intent listener |
| `database.dart` | All Drift tables + DAO methods (single file) |
| `quick_save_service.dart` | Quick Save flow + dedup logic |
| `enrichment_orchestrator.dart` | Background metadata processing |
| `metadata_adapter_factory.dart` | Route to correct adapter by platform |
